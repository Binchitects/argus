# People security policy

> A template. Replace each [bracket], remove what does not apply to you,
> approve it and set its review date.

| | |
|---|---|
| Owner | [HR, with the information security officer] |
| Approved by | [Name, role, date] |
| Review | every year |

## Before

1. Candidates are screened as the law allows and the role needs: [identity,
   references, background checks for admins and anyone seeing health data].
2. Contracts include confidentiality and the duty to follow the information
   security policies; contractors sign [an NDA].

## During

1. Everyone is trained on joining and every [year]: the acceptable use policy,
   spotting phishing, personal and health data, reporting incidents. Admins
   also on running Arena securely. Training is recorded.
2. Security reminders [monthly, by e-mail / in Arena's announcements].
3. Everyone accepts the acceptable use and privacy notice in Arena before using
   it, and again when it changes (Settings → Sign-in notice; each acceptance is
   in the evidence).
4. Breaking the policies follows [the disciplinary process], the same for
   everyone, in proportion to what was done.

## Leaving or changing role

1. [HR] tells [IT] by [the last day]; access ends then (the directory removes
   the Arena account; a hand-made one is disabled in Admin → People).
2. Devices, keys and badges are returned; confidentiality continues after.
3. A mover's access is changed to the new role's; the old is removed.

## Records

Screening done, contracts and NDAs, training, the disciplinary cases, leavers'
access removed. Kept [six years].
