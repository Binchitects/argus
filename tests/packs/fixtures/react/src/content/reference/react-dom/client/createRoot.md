<Intro>

`createRoot` lets you create a root.

</Intro>

## Reference {/*reference*/}

### `createRoot(domNode, options?)` {/*createroot*/}

Call `createRoot` to create a React root.

### `root.render(reactNode)` {/*root-render*/}

Renders a piece of JSX into the root.

### `<StrictMode>` {/*strictmode*/}

A component heading.
