parameters:
  - { name: idea, description: "What is proposed" }
  - { name: audience, description: "Who decides", required: false, default: "the management" }

Write a proposal for {{idea}}, for {{audience}} ($ARGUMENTS).

1. **Executive summary**: the problem, the proposal, the cost and the benefit, in five sentences.
2. **The problem**: what it costs today (time, money, risk, people), with evidence.
3. **The proposal**: what will be done and what changes for whom.
4. **Alternatives**, including doing nothing, and why this one.
5. **Plan**: phases, milestones, people and time; **budget** with its assumptions; the **return** (savings, revenue, risk reduced) and when it comes.
6. **Risks** and how they are handled.
7. **The ask**: exactly what is to be decided or approved, by when.

Write for a busy reader: the conclusion first, short sections, numbers where they persuade. Mark every assumption.
